# Omnixerio Redstone

_Yet another generic building blocks mod._  
**NOTE THAT ALPHA AND BETA VERSIONS MAY INCLUDE GAME BREAKING BUGS AND CRASHES**

## Features

*   Logic gates (AND/OR/XOR/etc.)
*   Timer
*   Switch
*   D flip-flop, JK flip-flop, SR Latch
*   Colored redstone lamps
*   And more!
